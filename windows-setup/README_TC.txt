Screen Wake v1 Windows 初始設定

完整解壓後，雙擊 START_SETUP.cmd。
先開啟平板 USB 偵錯、以 USB 線連接並允許偵錯授權。
選擇正確平板，按「開始初始設定」。
工具會安裝 ScreenWake_v1.apk、設定 Device Owner 並開啟 App。

已有公司 MDM／Knox 管理請交由 IT 處理。
系統拒絕設定時會停止；不會刪除資料、帳戶或重設裝置。
App 裏的初始設定按鈕只顯示說明、複製指令及檢查狀態，不能自行取得 Device Owner。

預覽為全螢幕，沒有 App 頂部工具列。用系統返回手勢／返回鍵輸入前線密碼即可管理。

完整步驟請見 ScreenWake_Setup_TC.md。

本工具需要 Windows PowerShell。啟動器的 ExecutionPolicy Bypass 只限本次程序。
未在實際 Windows + Tab S12 組合上驗證。
